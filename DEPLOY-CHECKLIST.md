# VRC Club Charts — operations checklist

This is an operational checklist for the current Club Discovery site. Older prototype launch tasks are archived and are no longer public-facing requirements.

## Verified configuration

- [x] Main site is publicly accessible at https://vrc-club-charts.vercel.app/
- [x] GitHub Pages build and validation workflows complete successfully
- [x] CLUB DISCOVERY has a visual-score-only chart, with clear image-only limitations
- [x] Gemini-powered image scouting has produced sample assessments
- [x] Open community field notes are separated from Gemini visual scores
- [x] Community reviews are moderated prior to publication
- [x] Supabase public table permissions deny direct anonymous review and application data reads/writes
- [x] Privacy policy covers community reviews, browser storage, and analytics
- [x] Old public reviewer-application and approved-panel review Issue forms retired

## Recurring operational checks

- [ ] Confirm the scheduled AI discovery and Pages publishing workflows continue succeeding
- [ ] Review API provider availability and quota usage periodically
- [ ] Inspect newly auto-discovered Worlds for catalog relevance; image score is not verification
- [ ] Moderate pending community reviews and investigate spam patterns
- [ ] Spot-check imported event dates and organizer links to reduce stale event information
- [ ] If a new advertising, analytics, or payment integration is introduced, update disclosures and controls before enabling it

## Archived systems

Historic reviewer panel submissions and approvals are kept as non-public records. They do **not** contribute to the current public visual chart.
